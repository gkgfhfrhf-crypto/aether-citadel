# AETHER CITADEL · 苍穹堡垒 V2
电影级真实科幻方向的可交互 3D 网页原型。

## 运行
- 需要联网加载 Three.js（CDN）。
- 推荐通过静态网站托管运行，不建议直接用文件管理器打开 `index.html`。
- GitHub Pages / Netlify / Vercel 等静态托管均可部署。
- 平板浏览器支持拖动旋转、滚轮/按钮缩放、全屏和拆解/复位。
- 默认暂停自动运动，避免镜头无故晃动。
- 画质可切换省电/平衡/高画质。

## 注意
这是可交互的程序化 3D 原型，不是电影级真实资产扫描模型；后续可继续替换高精度空间站、地球和飞船模型/纹理。
